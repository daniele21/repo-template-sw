# repo-template-sw

Reference engineering baseline for software repositories maintained by humans and coding agents.

This repository is the canonical source for a small, reusable engineering standard, an agent-operating model, project-local skills, documentation governance, and repository health checks.

The template is intentionally not a framework. Projects adopt the smallest applicable baseline, remain self-contained, and may specialize local copies when their domain requires it.
